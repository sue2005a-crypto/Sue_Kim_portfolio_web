Database Systems

SQL Database Management Project

Overview

A comprehensive relational database management project built using SQL Server. The project involved designing and implementing a complete database from the ground up, applying industry-standard database design principles and SQL programming techniques.

Objective

Design, create, and manage a relational database system that demonstrates proper data organization, integrity, and retrieval capabilities using SQL Server and structured query language.

My Role

Designed and implemented all database components including schema design, table relationships, data validation, and query logic. Responsible for applying normalization concepts and writing SQL code for views, stored procedures, and functions.

Technologies Used

  • SQL
  • SQL Server
  • Relational Database Design
  • Database Normalization

Challenges

Ensuring proper normalization while maintaining query performance, and managing referential integrity across multiple related tables with composite key relationships.

Solutions

Applied database normalization principles methodically and used SQL Server's constraint system to enforce data integrity. Designed stored procedures to encapsulate complex logic and improve maintainability.

Skills Gained

  • Database creation and schema design
  • Table relationships with primary and composite keys
  • Data validation with constraints
  • Writing SQL queries and joins
  • Creating views for data abstraction
  • Developing stored procedures and functions
  • Database normalization (1NF, 2NF, 3NF)

User Experience

Human-Computer Interaction Project

Overview

A team-based usability evaluation and user research project focused on assessing a software application from the user's perspective. The project involved structured evaluation methods, data collection, and evidence-based design recommendations.

Objective

Evaluate the usability of a software application by collecting user feedback, identifying usability problems, analyzing findings systematically, and proposing actionable design improvements based on user-centered design principles.

My Role

Collaborated with team members to plan and conduct usability sessions, facilitate user interviews, document findings, analyze the collected data, and present improvement recommendations to address identified usability issues.

Methods and Tools

  • Usability Testing
  • User Interviews
  • Data Analysis
  • User-Centered Design
  • Team Collaboration

Challenges

Coordinating team responsibilities during evaluation sessions, maintaining objectivity while analyzing qualitative feedback, and translating diverse user observations into prioritized, actionable recommendations.

Solutions

Established clear team roles before each session, used structured note-taking templates to capture consistent data, and applied affinity mapping to organize and prioritize findings before developing recommendations.

Skills Gained

  • Collecting and organizing user feedback
  • Identifying and categorizing usability issues
  • Analyzing qualitative and quantitative results
  • Team collaboration and communication
  • Presenting design recommendations
  • Applying user-centered design principles
